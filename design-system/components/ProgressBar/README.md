# ProgressBar

Thin 6px track and fill showing completion or a skill score.

**Source:** `.progress-track` and `.progress-fill` in `index.css`. Static rendition.

## Usage
- The track fills `track` and the bar fills `primary`. Both are fully rounded.
- Width changes animate over 0.6s on `cubic-bezier(0.16, 1, 0.3, 1)`.
- Always show the numeric value beside the bar.
