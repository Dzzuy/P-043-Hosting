# Icons

Outline icons on a 24px grid (the four feature marks use 48px): 2px stroke, round caps and joins. Topic icons use `stroke="currentColor"`, which shows as black through `<img>`. In product they are applied as CSS masks (`mask: url(...) center / contain no-repeat; background: currentColor`) so they take the surrounding colour, usually `blue-600` on a `blue-tint` tile.

Feature marks: `danh-gia-ky-nang` (skill review), `luyen-tap-tinh-huong` (scenario practice), `tra-cuu-co-nguon` (sourced lookup) and `roleplay-icon`. Some of these carry their own stroke colour (#679BCC).
