# Logos

- **vinfast-official-logo.png** (1402×1122): the chrome V emblem with the VINFAST wordmark. Use it on dark grounds only (`navy-950`, `navy-hero`), at 44px in the header and 56px on the login screen.
- **advisor-logo.png**, **manager-logo.png**, **copilot-logo.png** (1254×1254): role marks in a single blue ink (~#066bff) on transparent. The Copilot mark is applied as a CSS mask so it takes `currentColor`.
- **favicon.svg**: the app favicon, a chrome V on a dark disc.
